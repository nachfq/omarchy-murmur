# Omarchy Murmur

A small offline ambient sound mixer for Omarchy Shell.

Mix rain, thunder, waves, wind, fire, birds, crickets, coffee shop, singing bowl,
and white noise. Implementation is being delivered through three reviewable PRs.

Code: [MIT](LICENSE). Audio: [individual licenses](SOUNDS_LICENSES.md).
Inspired by [A Soft Murmur](https://asoftmurmur.com/); independently implemented
and not affiliated with its author. No files are extracted from that website.
